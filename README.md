# 百年藏历

轻量、可离线使用的公历与藏历对照工具，覆盖 1951-01-08 至 2051-02-11。项目是无框架静态 JavaScript 应用，包含简体中文、繁体中文、英文页面，以及仍处于隐藏测试阶段的藏文页面。

## 功能

- 公历与藏历月历对照、藏历反查
- 殊胜日、功德增广日和日月食信息
- 本地日期与北京时间两种“今天”口径
- 年度 `.ics` 导出、2026–2030 日历订阅
- PWA 安装与离线访问
- 日期深链接与多语言页面

## 本地运行

项目不需要安装运行时依赖。建议使用 Node.js 22 或更新版本。

```bash
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。静态服务器不会模拟生产环境的深链接重写；深链接规则见 `_redirects`、`.htaccess` 和 `nginx.conf`。

## 开发命令

```bash
npm test             # 日期、语言、页面、PWA 和订阅数据检查
npm run generate     # 生成四个语言入口、缓存版本和订阅文件
npm run verify       # 语法、产品测试和生成物一致性检查
```

修改页面模板或 `scripts/release-config.js` 后必须运行 `npm run generate`。生成的 HTML、`sw.js` 和订阅文件需要随源码一起提交。

## 数据口径

藏历对照来自《藏历、公历、农历对照百年历书（1951–2050）》。本地日期模式只决定查询哪个公历日，不会按用户所在地重新计算天文历法。不同寺院、传承或历书的日期可能存在差异。
